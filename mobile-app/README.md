# Food Donation Mobile App (React Native + Expo)

## Setup

1. Open terminal in `mobile-app`.
2. Install dependencies:

```bash
npm install
```

3. Start app:

```bash
npm run start
```

4. Run on device/emulator from Expo CLI.

## Features Included

- Home screen with search + live donation map markers.
- Volunteer screen with one-click pickup action.
- Community screen with leaderboard, badges, and AI demand prediction list.

## Backend URL

Update `src/services/api.js` if your backend runs on another host.
For Android emulator use `10.0.2.2` instead of `127.0.0.1`.
